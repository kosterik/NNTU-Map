## ✨ Возможности приложения

1. **🗺️ Полная карта 6 корпусов и 797 аудиторий:**
   - 1 корпус (ул. Минина, 24)
   - 2 корпус (ул. Минина, 24к2)
   - 3 корпус (ул. Минина, 28Б)
   - 4 корпус (ул. Минина, 28В)
   - 5 корпус (ул. Минина, 28Л)
   - 6 корпус (Казанское шоссе, 12)
   - Интерактивный просмотр планов этажей с плавным масштабированием (**Pan & Zoom**), переключением этажей, быстрым поиском кабинетов и готовыми маршрутами прямо до дверей аудитории.
   - **Мгновенный переход из расписания:** Клик по любой аудитории в расписании пар автоматически открывает нужный корпус и прокладывает путь!

2. **📅 Умное расписание занятий и звонки:**
   - Поддержка числителя и знаменателя (нечётная / чётная недели).
   - Подсветка текущей пары в реальном времени.
   - Официальное расписание звонков НГТУ (1–8 пары).
   - Работа в **полном офлайн-режиме** благодаря локальному кэшированию.

3. **🔑 Интеграция с личным кабинетом `lks.nntu.ru`:**
   - Отдельный защищённый шлюз авторизации студента.
   - Автоматическая синхронизация группы и актуального учебного плана.
   - Безопасное локальное хранение данных.

4. **👤 Раздельные профили:**
   - **Профиль приложения:** локальный, необязательный (выбор никнейма, аватарки, настроек).
   - **Учётная запись ЛКС:** студенческий аккаунт для подгрузки расписания с возможностью синхронизации в один клик.

5. **🔔 Уведомления и будильник пар:**
   - Настраиваемое время утреннего пуш-уведомления со списком пар на день.
   - Предупреждение за 15 минут до начала пары с указанием корпуса и аудитории.

6. **📱 Виджеты (Android + Windows):**
   - **Виджет 1:** «Пары на завтра» (для домашнего экрана и ПК).
   - **Виджет 2:** «Обзор двух дней: Сегодня + Завтра».
   - На Windows доступно всплывающее компактное мини-окно виджета.

7. **📰 Лента новостей с официального сайта:**
   - Автоматический парсинг свежих новостей из раздела `https://www.nntu.ru/news/all/vse-novosti`.

8. **🎨 Дизайн в стиле GitHub Primer Dark:**
   - Темная тема `#0d1117`, аккуратные бейджи, кнопки, карточки и типографика в духе интерфейсов GitHub.

## 🚀 Запуск на Windows

### Быстрый запуск (1 клик):
Дважды кликните по файлу:
```cmd
desktop\run_desktop.bat
```
Приложение откроется в нативном десктопном окне **Edge WebView2** (без лишних браузерных рамок, с аппаратным ускорением и плавной анимацией 60fps).

### Запуск через консоль:
```cmd
python desktop\app_desktop.py
```

## 📱 Сборка для Android

В репозитории подготовлен полноценный Android Studio проект со всеми нативными компонентами виджетов:
* `android/app/src/main/AndroidManifest.xml` — манифест с ресиверами виджетов и разрешений.
* `android/app/src/main/java/com/kosterik/nntu/`:
  - `MainActivity.java` — WebView клиент для запуска интерфейса.
  - `WidgetTomorrowProvider.java` — нативный виджет Android «Пары на завтра».
  - `WidgetDualProvider.java` — нативный виджет Android «Сегодня + Завтра».
  - `NotificationAlarmReceiver.java` — фоновый планировщик напоминаний.
* `android/app/src/main/res/` — макеты виджетов и иконки.

### Как собрать APK:
1. Откройте папку `android/` в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Нажмите **Build > Build Bundle(s) / APK(s) > Build APK(s)** или выполните:
   ```cmd
   cd android
   gradlew assembleDebug
   ```
4. Готовый `.apk` будет создан в `android/app/build/outputs/apk/debug/`.
